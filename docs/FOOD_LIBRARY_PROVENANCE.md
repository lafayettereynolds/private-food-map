Restaurant-name evidence, then cuisine/tag evidence, then category fallback.

labelled as an actual meal, merchant photo, avatar upload or recommendation author.
The other supplied sheets remain reference material; this is the Restaurant-main-
image subset, not completion of the separate Analytics/poster asset work.
