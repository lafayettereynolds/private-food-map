Taste Map 隐私政策

生效日期：2026 年 9 月 10 日

1. 我们是谁

Taste Map 是一款用于记录餐厅到访、整理个人美食地图，并提供个性化餐厅发现与推荐的应用。

2. 我们可能处理的信息

根据你实际使用的功能，Taste Map 可能处理以下信息：

  • 账号信息：Taste Map userID、Apple 登录标识、姓名或显示名称，以及 Apple 返回的电子邮箱（包括隐藏邮箱转发地址），用于注册、登录、账号安全及数据同步。
  • 餐厅与到访记录：包括你保存的餐厅、到访时间、评分、备注、评论、菜品、消费记录、想吃状态、食单和食单条目等。
  • 照片：仅在你主动选择或拍摄照片并上传时处理，用于展示你的餐厅或到访记录。
  • 位置信息：设备定位在你授权后用于附近餐厅和地图定位；你保存、同步的餐厅和到访记录包含具体地点坐标与城市，个人资料也可包含你填写的城市。选定城市或保存地点不等于持续上传设备 GPS 轨迹；我们不请求后台持续定位。
  • 请求与诊断信息：服务运行日志保存请求路径、查询参数、时间、响应状态及执行耗时等技术信息，用于安全与故障排查。搜索用户等请求中的查询词会进入请求日志；这不同于只保存在设备上的搜索记录。我们不把本地调试日志等同于自动上传的崩溃报告。
  • 社交与推荐相关信息：关注、粉丝、好友、屏蔽关系、关联的饭搭子和推荐来源，以及点赞、举报和明确的不感兴趣偏好等。社交关系不是读取你手机的通讯录。
  • 支持信息：你主动通过支持邮箱发送的联系方式、问题描述及附件，用于回应请求和处理问题。请勿发送密码或验证码。

使用“通过 Apple 登录”时，我们处理 Apple 返回的账户标识及你授权提供的姓名、电子邮箱，并将其与 Taste Map 用户标识关联，用于登录、同步和账户安全。

使用 Premium 时，我们仅处理提供和验证会员权益所必需的交易与权益信息，包括 StoreKit 交易标识、原始交易标识、商品 ID、权益状态、有效期、撤销或退款状态以及交易环境。我们通过 Apple App Store Server API 验证交易，并接收 App Store Server Notifications 以更新权益。

Taste Map 不收集你的银行卡号或完整支付卡信息，付款由 Apple App Store 处理。赠送会员和邀请奖励不是支付卡信息；为分配权益、避免重复发放及处理奖励状态，我们保存必要的赠送权益、邀请关系、奖励状态与奖励记录。邀请功能关闭时，已有记录仍依照本政策处理。

3. 我们如何使用这些信息

  • 保存并同步你的 Taste Map 数据。
  • 展示你的个人餐厅地图、到访历史和收藏内容。
  • 根据你的记录、偏好和当前使用场景提供个性化推荐。
  • 提供账号、安全、客服、故障排查与服务改进。
  • 在你明确选择公开或与好友共享时，向相应用户展示你允许共享的内容。

4. 权限说明

定位权限：用于地图定位、附近餐厅和基于位置的推荐。拒绝授权后，你仍可使用不依赖定位的功能。

照片：系统照片选择器仅向 App 提供你选择的照片，不要求读取完整相册。只有你主动保存回忆或分析海报时，才请求向系统相册添加图片的权限。删除 Taste Map 中的照片不会删除系统相册原图。

相机权限：仅在你主动拍摄用餐或菜品照片时使用。

我们不请求手机通讯录、麦克风或蓝牙权限。定位只请求使用 App 期间的授权，不请求始终定位。

5. 第三方服务

我们实际使用以下系统服务和基础设施：

  • Apple：提供“通过 Apple 登录”、StoreKit、App Store 交易验证及服务器通知。传输范围限于身份验证和购买权益处理所需的信息，不意味着 Apple 获取 Taste Map 的全部业务数据。
  • Apple MapKit：提供地图、地点搜索和导航等能力；相关请求可能涉及你授权的位置、搜索区域或地点信息。Taste Map 会保存你记录的餐厅坐标和城市，不持续记录后台移动轨迹。
  • Cloudflare Workers：处理账户认证、数据同步、内容访问控制和会员权益等请求；D1 保存相应结构化记录；R2 保存你选择上传的照片及缩略图。图片通过所有权和可见范围校验后提供访问。
  • Open-Meteo：在指定搜索城市时解析城市名称，请求包含城市查询词、语言及必要网络信息；不发送你的 Taste Map 登录凭证。详见 Open-Meteo 隐私说明。
  • Photon（photon.komoot.io）：用于部分城市的餐厅搜索及地点搜索回退，请求包含搜索词、选定城市的中心和范围及必要网络信息，不发送 Taste Map 登录凭证。地点数据基于 OpenStreetMap，服务见 Photon。
  • QQ 邮箱（腾讯）：接收你主动发送的支持邮件，包括发件人地址、问题描述和附件；不会因此自动取得你的 Taste Map 业务数据库。

上述服务按各自职责处理相应数据。本政策不表示 Cloudflare 将 Taste Map 用户数据用于广告。

6. 信息共享与公开

我们不会出售你的个人信息。除以下情况外，我们不会向无关第三方披露你的个人信息：

  • 获得你的明确授权；
  • 为提供服务所必需，由受约束的服务提供商处理；
  • 根据法律法规、司法或行政机关的合法要求；
  • 为保护用户、平台或公众的合法权益和安全所必要。

对于你设置为公开、好友可见或其他共享范围的内容，将按照你选择的可见范围展示。

7. 数据保存与安全

我们采取合理的技术和管理措施保护数据安全。正式服务已启用以下分批保留与清理规则。

账户删除完成不代表所有系统中的数据在点击时立即永久消失。为保证多设备同步、重试和防止旧设备恢复已删除内容，普通删除记录的业务内容保留 30 天后进入清理；账户删除后的到访、餐厅、UGC 内容及私有头像也在 30 天后进入清理。图片对象必须先删除，随后才清除对应存储引用。批量清理失败时会继续重试。

精简的记录标识、关联标识、删除时间和同步版本会在账户存续期间保留，用于正确下发删除状态；这些仍是关联数据，不称为匿名数据。账户关闭满 365 天后，相关业务记录、同步历史、删除任务记录和账户记录进入最终物理清理。

已撤销的安全会话及其刷新记录在撤销满 90 天后进入清理；过期登录挑战、已使用身份令牌的防重放记录及公共接口限流记录，分别在过期、使用或对应窗口开始满 90 天后进入清理。已关闭账户的举报记录在最后更新满 90 天后、推荐事件在记录或接收满 90 天后、私有目录审计在创建满 90 天后进入清理；这不表示仍在使用的账户的所有记录都会在 90 天后删除。

为交易核对和争议处理，必要的 Apple 交易及所有权证明保留至账户关闭、相关交易结束或撤销、最后更新及验证均满足 365 天条件，且不再支撑有效订阅后，再进入清理。符合条件、已处理且不再被交易引用的服务器通知记录，在处理满 365 天后进入清理；会员与邀请审计还要求相关账户已经关闭满 365 天。若邀请关系仍支撑另一位用户尚未结束的奖励，最低限度的权益来源关系会保留到该奖励结束后 365 天；另一位用户仍有效的长期权益不会因邀请人删除账户而消失。已删除的到访内容和照片不因该关系而继续保留。

未完成的删除任务、仍必需的同步删除标识、有效订阅及关联记录，以及待处理举报调查涉及的记录，不会仅因达到天数而跳过依赖检查被清除。法律或安全调查需要保留的记录按必要范围处理。Cloudflare 请求与诊断日志使用独立的日志保留机制，不适用上述 D1 业务记录的统一期限；当前 Workers Paid 日志最长保留 7 天。

上述保留窗口是 Taste Map 的数据处理规则，不表示所有记录均受同一法定期限约束。清理按批次执行，失败时会重试；达到保留期限表示进入清理流程，不代表所有系统或备份在同一时刻完成删除。

8. 你的权利

你可以访问、更正、删除自己的记录，并可以在系统设置中撤回定位、照片等权限。

你可以在“我的 → 设置 → 账户与安全 → 删除账户”发起删除，并按提示重新验证身份和确认。删除处理开始后，账户停用，已有会话失效，相关公开内容撤下。完成身份清理后，Apple 身份关联和邮箱会从账户记录中移除。

你的 R2 照片原图与缩略图按账户范围分批删除。只有待处理清单和重新查询的账户图片范围均为空时，照片清理才视为完成。失败或中断的任务保留可重试状态，不会以成功代替失败。

9. 未成年人

Taste Map 不以未成年人为主要目标用户。如果法律要求获得监护人同意，我们将按照适用规则处理。

10. 政策更新

如果我们的功能、数据处理方式或法律要求发生变化，我们可能更新本隐私政策，并在本页面发布新的版本及生效日期。
