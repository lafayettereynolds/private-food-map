# 食途 · 私人美食地图

食途是一个本地优先的私人美食足迹 Web App，用来记录去过和想去的餐厅、每次到访、评分、消费、排队时长、饭搭子、菜品、照片与个人感受。高德地图提供地图、定位、餐厅搜索和路线导航；私人记录默认只保存在当前浏览器中。

## 主要功能

- “我去过 / 我想去 / 推荐”三份清单与多维筛选
- 通过高德搜索添加餐厅，也支持手动添加地图中没有的小店或摊位
- 每次到访可记录总价、人数、评分、排队时长、饭搭子、菜品、口味、照片和感受
- 自动汇总到访次数、10 分制评分、平均人均、平均排队时长和最近到访
- 地图使用餐厅图片或表情作为标记，外圈颜色表示个人喜好
- 设置中支持完整 JSON 数据导出和合并导入

## 环境要求

- Node.js 18 或更高版本
- pnpm（推荐）或 npm
- 高德开放平台 Web 端（JS API）Key 与安全密钥

## 安装依赖

```bash
pnpm install
```

也可以使用：

```bash
npm install
```

## 配置环境变量

将 `.env.example` 复制为 `.env`：

```env
VITE_AMAP_KEY=
VITE_AMAP_SECURITY_CODE=
```

在本地 `.env` 中填入高德 Web 端 Key 和安全密钥。`.env`、`.env.local` 及其他本地环境文件已被 Git 忽略，不能提交到仓库。修改环境变量后需要重新启动开发服务。

没有配置 Key 时，应用仍可读取本地数据，但地图、定位和高德餐厅搜索不可用。

## 本地运行

```bash
pnpm dev
```

打开终端显示的地址，默认通常是 `http://localhost:5173/`。

Windows 用户也可以运行 `scripts/start-food-map.ps1`。脚本会优先使用系统中的 Node.js 与 pnpm，并兼容 Codex 自带的本地运行环境。

## 构建与预览

```bash
pnpm build
pnpm preview
```

构建产物生成在 `dist/`，该目录不提交到 Git。

## 数据存在哪里

餐厅和到访数据保存在浏览器 IndexedDB 的 `private-food-map` 数据库中，照片也作为私人记录的一部分保存在本地数据库。常用城市等少量界面偏好保存在浏览器 localStorage。

这些数据不会因为代码推送到 GitHub 而自动上传。不同浏览器、浏览器用户资料、设备和站点地址的数据彼此独立；清除站点数据会删除本地记录。

## 备份数据

1. 打开页面右上角的设置。
2. 选择“导出完整备份”。
3. 将下载的 JSON 文件保存在安全位置。

备份包含餐厅、到访历史、评分、照片、菜品、标签和笔记。备份文件属于私人数据，不应加入 Git 仓库。

## 恢复数据

1. 打开设置。
2. 选择“导入食途备份”。
3. 选择此前导出的 JSON 文件。

导入会与当前数据合并，不会先清空已有餐厅和到访记录。建议在导入前先导出一份当前数据备份。

## 项目结构

```text
src/
├── components/       页面组件、地图、弹窗与表单
├── db/               IndexedDB 数据库、数据操作与备份恢复
├── services/         高德地图加载、定位与 POI 搜索
├── styles/           全局界面样式与响应式适配
├── types/            领域数据类型
├── utils/            日期和图片处理工具
├── App.tsx           主流程、筛选与本地推荐
└── main.tsx          应用入口
```

## 隐私与仓库安全

仓库不应包含以下内容：

- `.env`、API Key、安全密钥、token 或密码
- `node_modules/`、`dist/` 等依赖和构建产物
- IndexedDB、本地数据库文件、导出的备份文件
- 用户餐厅数据和用户照片

提交前请检查 `git status`，确认只包含预期的源代码和文档。
